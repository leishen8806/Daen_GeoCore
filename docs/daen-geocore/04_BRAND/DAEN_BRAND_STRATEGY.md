# DAEN BRAND STRATEGY

- Primary brand candidate: ដែន · DAEN · 域联 — `RECOMMENDED`
- Strategic positioning: Cambodia Location Infrastructure — `CANDIDATE`
- Long-term expression: Cambodia Location Network — `CANDIDATE`

This document preserves the source decision status. No trademark, language, domain or account availability is treated as confirmed.

## 2. Brand Structure

DAEN is the proposed brand and infrastructure umbrella. DAEN Geo Core is the proposed core location technology platform.

The working brand system is:

| Layer | Name | Status |
|---|---|---|
| Khmer | ដែន | `RECOMMENDED` |
| English | DAEN | `RECOMMENDED` |
| Chinese | 域联 | `RECOMMENDED` |
| Positioning | Cambodia Location Infrastructure | `CANDIDATE` |
| Long-term expression | Cambodia Location Network | `CANDIDATE` |
| Mission line | Connect Every Place. | `CANDIDATE` |
| Technology platform | DAEN Geo Core | `RECOMMENDED` |

The brand should remain broad enough to cover place identity, addresses, places, access, routes, mobility, logistics and location APIs. The exact product naming must follow confirmed capability and user boundaries.
