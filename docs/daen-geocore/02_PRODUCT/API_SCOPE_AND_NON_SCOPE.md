# DAEN Geo Core — Phase 05A API Scope and Non-Scope

## Status

`PHASE 05A RESOURCE MODEL = HUMAN FROZEN`

## API Core

- Place / GeoID
- Source Assertion
- Current DAEN Representation
- Access Point
- historical identity resolution
- Provenance / Quality

Supporting contracts: Extent, Correction history, Resolution Link, Succession, Merge / Split / Closure / Withdrawal, and Containment.

## Explicit non-scope

Business/tenant/organization registry; pickup/drop-off workflow; delivery/logistics policy; pricing/service zones; Route; Area; Street/network; source ranking; trust scoring; database persistence; provider orchestration; consumer-map UI; market/search-discovery semantics; production architecture.

No endpoints, OpenAPI, JSON Schema, database tables, architecture, or provider selection are defined in Phase 05A.
