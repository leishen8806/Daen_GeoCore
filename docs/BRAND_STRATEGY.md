# 品牌策略与命名候选

> 来源：用户提供的品牌分析稿。此文档归档其推荐和论据，不代表名称、定位、商标或域名已完成正式决策与核验。

## 推荐方向

**ដែន · DAEN · 域联**

- **高棉文**：ដែន（原稿给出的读音近似 Daen / Den）。原稿将其解释为区域、疆域、领域、范围，并提到可表达 Domain。
- **英文品牌**：DAEN。建议主品牌不限定为 “DAEN Maps”。
- **中文品牌**：域联，取“地域 + 连接”的意译，表达将人、店、货、车、仓、道路和入口连接到同一位置网络。
- **品牌定位候选**：Cambodia Location Infrastructure / 柬埔寨位置基础设施。
- **长期战略候选表述**：Cambodia Location Network。
- **使命候选**：Connect Every Place. / 连接每一个真实地点。

原稿建议将 DAEN 作为品牌，Geo Core 作为核心技术平台，并把 Cambodia Location Network 作为长期战略表述。

## 候选产品体系

原稿提出的品牌延展方向包括：

| 产品名 | 方向 |
|---|---|
| DAEN ID / Location ID | 地点身份 |
| DAEN Places | POI 与地点信息 |
| DAEN Access | 入口与最后一公里访问点 |
| DAEN Route | 路线 |
| DAEN Move / Mobility | 移动与交通 |
| DAEN Logistics | 物流网络 |
| DAEN Cloud / DAEN API | 对外位置服务与 API |
| Geo Core | 核心技术平台 |

这些是命名与架构候选，不是已确认的产品模块清单。

原稿 shortlist 排序为 DAEN、NOKOR、PHLOV，并选择 DAEN 作为第一推荐。

## 推荐理由（按原稿归纳）

原稿认为 DAEN 的语义范围较宽，可以覆盖地点身份、地址、POI、入口、路线、移动、物流和 API，不会像 Map、配送或导航类名称那样锁定单一业务。中文“域联”则突出地域与连接关系。
