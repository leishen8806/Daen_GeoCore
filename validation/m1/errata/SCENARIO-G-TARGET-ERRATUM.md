# Scenario G Target Erratum

## Historical registration

The original frozen Scenario G targets were `P08, P09`, registered in:

- `validation/m1/scenario-sheet.md`
- `validation/m1/runbook.md`

## Defect

Frozen corpus evidence identifies:

- P08 = Hun Sen Library, RUPP
- P09 = Royal Phnom Penh Hospital

The frozen evidence does not support P08/P09 as the same Place. Using them for a Merge test would require inventing a same-Place judgment contrary to the registered corpus.

Classification: `VALIDATION PREREGISTRATION / TARGET-SELECTION DEFECT`

This is **NOT DOMAIN MODEL FRICTION**.

## Intended merge pair evidence

`validation/m1/corpus-register.csv` assigns P15 and P16 to G.

`validation/m1/synthetic-case-plan.md` defines:

- P15 as a synthetic seed record;
- P16 as a second synthetic record representing the same intended locus as P15.

## Human decision

The effective Scenario G execution targets are prospectively corrected to:

`P15, P16`

This erratum changes only the effective execution target registration. It does not change the Scenario G name, merge action, expected outcome, invariant intent or Domain Model semantics.

## Historical preservation

The following remain unchanged and are preserved as historical evidence of the original inconsistency:

- `validation/m1/scenario-sheet.md`
- `validation/m1/runbook.md`
